# Nocturne: 150-species regional roster

These 150 use new species names. The three canonical distorted starter expressions remain separate, outside this roster. Existing Kanto data stays underneath for engine compatibility. No new ending or automatic encounters are added.

First-pass designs use muted colors, pale eyes, worn organic shapes and signs of care amid abandonment. These are design briefs and procedural prototype sprites, not finished character sheets. Evolutions use levels so every family can evolve offline. Battle data uses the engine’s five-stat system; moves are existing engine moves. Habitat names beyond the current opening are worldbuilding proposals, not implemented maps.
